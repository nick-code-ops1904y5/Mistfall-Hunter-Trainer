## || 📖 About 

***MH-trainer***

We focus on:

⚡ **Performance** - fast loading, high execution speed, and minimal impact on system performance.

🛡️ **Stability** - stable operation, compatibility with the latest versions of Windows, and constant updates.

## || 🎮 Features 

### || ⚡ Player ESP
Names, distance, HP / stamina bars
Skeleton (optional vis check)
Snaplines (including off-screen)
Optional teammates (green)
Bot tag
Player glow outline

### || ⚡ Enemy ESP
Names, distance, HP bars
Skeleton (optional vis check)
Hide dead / lurking filters
Optional MonsterID / NameID
Enemy glow outline

### || ⚡ Treasure ESP
Chests / treasure labels
State, distance, item names
Optional item icons / raw CfgIds
Hide fully looted, max distance

### || ⚡ Loot ESP
Player & enemy loot bags
Item names, state, distance

### || ⚡ Aimbot
Players and enemies
Bone select (head / neck / chest / pelvis / root)
Hotkey bind, FOV, distance
Target lock, LOS, skip bots / teammates
Smooth or instant aim
Optional hard camera snap with instant aim
